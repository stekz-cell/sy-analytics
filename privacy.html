Privacy Policy – SY Analytics

Last updated: October 18, 2026

What the app accesses

With the account owner's permission, SY Analytics uses Google OAuth with the read-only scopes yt-analytics.readonly and youtube.readonly to read YouTube Analytics reports and channel/video metadata for the channel SY AI Creators.

How data is used

The data is used only to create internal performance reports for the channel owner. It is not sold, shared with third parties, or used for advertising.

Storage

Data and access tokens are stored only on the channel owner's own systems. Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

SY Analytics' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube data is accessed via YouTube API Services; see the Google Privacy Policy at https://policies.google.com/privacy.
